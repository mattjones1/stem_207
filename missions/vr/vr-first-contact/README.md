# VR First Contact (VR / AR Workshop 1)

**STEM 207 · Virtual Reality · Grades 5–8 · 90 minutes**
**Equipment:** 10 Meta Quest 3 headsets for 9 students · **Workshop plan:** Luke Peelen for STEM Coliseum, 2025–2026

> *Your first step into a virtual world.*

Students try VR for the first time. The workshop is about comfort, curiosity, and a first understanding of what VR is and how it works. By the end, every student has set up a safe play space, made an avatar, watched 360° video, explored a 3D place in Wander, seen AR passthrough, and run a landmark scavenger hunt.

On the site: **Mission library → Virtual Reality → VR First Contact** (`#/activity/vr-first-contact`).

## Things to check before the first run

These came from the workshop plan and haven't been confirmed in a STEM 207 classroom yet.

- **Age guidance.** The plan says Meta recommends VR for ages 13 and up. Meta lowered its Quest minimum age to 10 in 2023, with parent-managed accounts for ages 10–12. Check Meta's current safety guide and your program's permission policy.
- **App prices.** The plan lists Wander as free (basic). The Quest store listing we found shows $9.99. Nature Treks VR is listed at about $5. Confirm both in the Meta Horizon Store.
- **Menu names.** Quest updates rename things. "Guardian" is now usually called the **boundary**.
- **Timing.** The 90-minute plan hasn't been timed in a STEM 207 session yet.
