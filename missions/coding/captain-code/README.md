# Captain Code (the flagship coding workshop)

**STEM 207 · Coding · Grades 2–8 · 90 minutes · A laptop, Chromebook, or tablet per student or pair**
**Runs inside STEM 207:** no outside accounts or websites. An original STEM 207 workshop (2026).

> *Your boat only goes where your code tells it.*

Students captain a Maine lobster boat through the 10 levels of Casco Bay:
- sequences and planning;
- debugging another captain's program;
- loops;
- if / else in the fog;
- one program for two tides;
- a variable;
- a block of their own.

They finish by designing their own voyage, printing a Voyage Card, and seeing their code in Python. Finishing Casco Bay earns the Casco Bay Certified Captain certificate and patch. Penobscot Bay and Down East (24 more levels) are for early finishers.

On the site: **Activity library → Coding & Computer Science → Captain Code** (`#/activity/lab-captain-code`). The lab is `#/lab/captain-code`, and the workshop Learning Plan template is **Captain Code Workshop**.
