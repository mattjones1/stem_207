# STEM 207 Website Builder

**STEM 207 · Coding (Web development) · Grades 4–8 · 60–90 minutes · A Chromebook or laptop with a keyboard per student**
**Runs inside STEM 207:** the builder follows rules (it isn't AI), the preview can't run scripts or reach the internet, and the website stays on the device. An original STEM 207 lab (2026).

> *Your ideas. Your website. Your code.*

Students describe a website in everyday words by answering seven questions. STEM 207's rule-based builder turns the answers into a real first version in HTML and CSS. Then the real work starts: in the Coding Studio, students:
- find the code that makes each part of their page;
- change headings, words, colors, fonts, and spacing;
- add something the builder didn't make;
- fix three bugs in a practice copy;
- think about what a program can and can't do, and make one improvement of their own;
- test the page like a visitor and finish it.

Finishing all 8 activities earns the Website Developer certificate.

## Things to check before the first run

- **Timing.** The plan hasn't been timed in a STEM 207 class yet.
- **The builder isn't AI.** Tell students before they start: it matches keywords and fills in templates, and it only knows what they tell it.
- **Privacy.** Students shouldn't type a full name, address, school, or phone number. The interview says so too.
