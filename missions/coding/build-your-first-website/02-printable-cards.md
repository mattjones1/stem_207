# Build Your First Website: printable cards

Print one wireframe sheet, one five-second test card, and one exit ticket per student.

---

## My wireframe (stage 1)

**My business (circle one):** Casco Bay Bakery · Pine Coast Kayak Rentals · Harbor Bait & Tackle

**The one thing a customer most needs to find:** ______________________________

Draw **boxes with labels**. No coloring needed. Put the most important thing near the top.

```
+--------------------------------------------------+
|  o o o                                           |
+--------------------------------------------------+
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
+--------------------------------------------------+
```

**Box labels to use:** Title (h1) · Section heading (h2) · Description (p) · List (ul) · Picture (img) · Link (a)

---

## Five-second test

**Tester:** look at the wireframe for **5 seconds**. Then it gets hidden.
**Designer:** don't explain your page. Just ask and listen.

1. What is this business?

   ______________________________________________

2. What does it offer?

   ______________________________________________

3. Where would you look next?

   ______________________________________________

**What my tester noticed first:** ______________________________

**One thing I'll change because of it:** ______________________________
