# Build Your First Website (the web workshop)

**STEM 207 · Coding (Web development) · Grades 2–8 · 90 minutes · A Chromebook or laptop with a keyboard per student**
**Runs inside STEM 207:** the preview can't run scripts or reach the internet, and student code stays on the device. An original STEM 207 workshop (2026).

> *Plan, code, test, and launch a web page for a made-up Maine business.*

Students become web developers for a made-up Maine business: a bakery, a kayak rental, or a bait and tackle shop. They:
- sketch a wireframe on paper and test it with a partner for five seconds;
- write real HTML and CSS;
- check headings, alt text, link words, and color contrast;
- fix a broken page another developer left behind;
- ship a page of their own that works on a phone.

Finishing stage 8 earns the First Website Shipped certificate.
