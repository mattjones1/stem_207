# Teach the Computer Your Secret Signals

**STEM 207 · Artificial Intelligence · Grades 2–8**
**Platform:** Google Teachable Machine → <https://teachablemachine.withgoogle.com/>

> *You're designing a contact-free control system for a space station. Can you train a computer to recognize two secret hand signals, and recognize when neither signal is present?*

Students build an **Image Project** with three classes (**Open hand**, **Closed fist**, **No signal**), train it, test it with new examples, find a position where it struggles, add more varied examples, and retrain. Everything happens in Teachable Machine itself. Nobody publishes, uploads, or exports a model.

## Learning goal

Students explain the difference between **training examples** (what the model learns from) and **new test examples** (what it has never seen). They also show how changing the training data changes the predictions.

## Time

- **Teacher setup:** about 20 minutes, done once before class (see the teacher guide).
- **Student activity:** about 45 minutes in one session. Teachable Machine doesn't keep work after the tab closes, so don't split it across days without reading the teacher guide first.
