## Decision Room discussion card (stage 7)

**For each one, choose: AI can help · AI can help, but a person reviews · AI should not decide**

| ✓ | Situation | My decision | My reason |
| --- | --- | --- | --- |
| ☐ | Counting puffins in wildlife photos from a Maine seabird island | | |
| ☐ | Sorting Maine wild blueberries by size and quality | | |
| ☐ | Helping a school library sort books by subject | | |
| ☐ | Recommending music based on what someone likes | | |
| ☐ | Helping a scientist spot unusual weather patterns | | |
| ☐ | Deciding whether a student should be disciplined | | |
| ☐ | Helping a doctor review X-rays and other medical images | | |
| ☐ | Deciding who receives a scholarship | | |
| ☐ | Helping translate town information into other languages | | |
| ☐ | Deciding whether a person should receive emergency assistance | | |

**Reasons to choose from:**
- A mistake would be small and easy to catch.
- It saves people time.
- A person still makes the final choice.
- A mistake could hurt someone.
- It could treat some people unfairly.
- It uses private information.
- The training examples could be missing some cases.
- The AI can't really know this from the data.

**Ask each other:** how bad would a mistake be, and who could be harmed?
