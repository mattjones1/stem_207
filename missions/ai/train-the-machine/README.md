# Train the Machine: How AI Learns, and When It Gets It Wrong (STEM Coliseum AI Workshop 1)

**STEM 207 · Artificial Intelligence · Grades 2–8 · 90 minutes · A Chromebook, laptop, or tablet per student or pair**
**Runs inside STEM 207** (the Pattern Machine Lab). A real model runs in the browser on made-up creatures only: no cameras, accounts, or personal information. A STEM Coliseum AI workshop, built for STEM 207 (2026).

> *A machine can find patterns. People decide whether those patterns are useful, fair, and trustworthy.*

Students become AI trainers. They:
- find the rule that sorts made-up creatures;
- build and label a training set;
- train a real k-nearest-neighbors model, and see exactly which examples it compared;
- run a fair accuracy experiment;
- find and fix biased data;
- catch a confident mistake;
- decide when AI should help and when a person must decide.

They finish with a printable AI Model Report and the Responsible AI Explorer certificate.

On the site: **Activity library → Artificial Intelligence → Train the Machine** (`#/activity/lab-pattern-machine`). The lab is `#/lab/pattern-machine`.
